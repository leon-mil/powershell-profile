# powershell-profile

PowerShell 7 profile with centralized aliases, profile/predictor development helpers, PSReadLine prediction controls, Git utilities, CPRS build/deployment workflows, and verified backup/archive commands.

## Documentation

See [`docs/PowerShell_Profile_and_ProfileAliasPredictor_Guide.md`](docs/PowerShell_Profile_and_ProfileAliasPredictor_Guide.md) for the complete setup guide, every alias and function, predictor setup, CPRS workflows, backup/ZIP/unzip usage, troubleshooting, and new-user installation steps.

## Quick health check

```powershell
ppath
predinfo
predtest
predstate
phelp
```

The predictor is maintained as a separate Git repository under:

```text
$HOME\Documents\PowerShell\Projects\ProfileAliasPredictor
```
